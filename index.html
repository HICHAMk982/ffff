Initiation à l'Informatique & Windows 10

Infographie détaillée de tous les concepts de base du matériel et du système d'exploitation.

1. Le Système Informatique

Matériel (Hardware)

La partie physique et palpable de l'ordinateur (Écran, unité centrale, clavier)[cite: 1].

Logiciel (Software)

La partie immatérielle. L'ensemble des programmes qui font fonctionner le matériel[cite: 1].

2. Les Composants Internes de l'Unité Centrale

Processeur (CPU)

Le cœur de l'ordinateur. Traite les informations et exécute les instructions (vitesse en Hertz)[cite: 1].

Mémoire (RAM)

Mémoire vive, très rapide et temporaire. Stocke les données utiles pendant le fonctionnement[cite: 1].

Disque Dur

Mémoire de masse. Stockage permanent des informations, programmes et OS[cite: 1].

Carte Mère

La colonne vertébrale. Centralise toutes les données et relie tous les éléments[cite: 1].

Les Périphériques

Périphériques d'Entrée

Fournissent des informations au système.
Ex: Clavier, Souris, Scanner, Webcam[cite: 1]

Périphériques de Sortie

Font sortir des informations du système.
Ex: Écran, Imprimante, Haut-parleur[cite: 1]

Entrée / Sortie

Opèrent dans les deux sens (Stocker et lire).
Ex: Clé USB, Disque Dur externe[cite: 1]

3. Le Langage Binaire

Le codage binaire (base 2) consiste à utiliser deux états (représentés par les chiffres 0 et 1) pour coder les informations[cite: 1].

1 VRAI (Courant passe)[cite: 1]
0 FAUX (Courant ne passe pas)[cite: 1]

4. Les Unités de Mémoire

L'octet est une unité d'information composée de 8 bits. Table de conversion :

  • 1 Octet (o) 8 bits[cite: 1]
  • 1 Kilo-octet (Ko) 1024 octets[cite: 1]
  • 1 Méga-octet (Mo) 1024 Ko[cite: 1]
  • 1 Giga-octet (Go) 1024 Mo[cite: 1]

5. Environnement Windows 10

La Barre des Tâches

  • Menu Démarrer : Lance les applications, ouvre les paramètres, et gère l'alimentation de l'ordinateur[cite: 2].
  • Fenêtre Cortana : Boîte de recherche permettant de trouver des fichiers sur le PC et sur le web[cite: 2].
  • Zone des applications : Contient les raccourcis favoris. La présence d'un trait blanc sous une icône indique que l'application est ouverte[cite: 2].
  • Zone de notification : Informe sur l'état de certains programmes (date, batterie, réseau, antivirus)[cite: 2].

6. Le Copier-Coller et le Presse-papier

Le presse-papier est une zone de mémoire "tampon" qui stocke temporairement vos données lors d'une duplication ou d'un déplacement[cite: 2].

Action Raccourci Clavier Résultat (Ce qui se passe)
Copier Ctrl + C Duplique les données dans le presse-papier. Le fichier d'origine reste à sa place[cite: 2].
Couper Ctrl + X Déplace les données dans le presse-papier. Le fichier d'origine disparaît de sa place initiale[cite: 2].
Coller Ctrl + V Place l'élément (préalablement copié ou coupé) à l'endroit de destination sélectionné[cite: 2].
Annuler Ctrl + Z Raccourci très utile pour annuler ou défaire la toute dernière action effectuée[cite: 2].
